## 🌐 مشاركة النظام على الشبكة المحلية

لتمكين الطلاب والمعلمين في المدرسة من الوصول:

### 1. اعرف IP جهازك
**Windows:**
```cmd
ipconfig
```
ابحث عن: `IPv4 Address` مثل: `192.168.1.100`

**Mac/Linux:**
```bash
ifconfig | grep inet
```

### 2. شغّل السيرفر على الشبكة
في `app.py` السطر الأخير محدد بالفعل:
```python
app.run(debug=False, host='0.0.0.0', port=5000)
```

### 3. يدخل الطلاب والمعلمون من أي جهاز في الشبكة:
```
http://192.168.1.100:5000
```
*(استبدل الـ IP بـ IP جهازك)*

### 4. فتح البورت في جدار الحماية (Windows)
```cmd
netsh advfirewall firewall add rule name="ExamSystem" dir=in action=allow protocol=TCP localport=5000
```

```

```

## 🆘 حل المشاكل الشائعة

**المشكلة:** `ModuleNotFoundError: No module named 'flask'`
**الحل:** `pip install flask PyJWT reportlab openpyxl pandas`

**المشكلة:** `Port 5000 already in use`
**الحل:** غيّر الرقم في `app.py`: `port=5001`

**المشكلة:** الطلاب لا يستطيعون الوصول
**الحل:** تأكد أن `host='0.0.0.0'` في `app.py` وافتح البورت في الفايروول

**المشكلة:** نسيت كلمة مرور المدير
**الحل:**
```python
python3 -c "
import sqlite3, hashlib
conn = sqlite3.connect('data/exam_system.db')
h = hashlib.sha256('newpassword123'.encode()).hexdigest()
conn.execute('UPDATE users SET password_hash=? WHERE username=?', (h, 'admin'))
conn.commit()
print('Done')
"
```
